# GTM Starter Kit

The skills and playbooks for the Treford GTM Engineering Bootcamp. Copy them into your own Context OS and Claude Code can use them straight away.

## What's inside

Coming before the Week 1 build-along:

- `.claude/skills/`: Claude Code skills for signal matrices, campaign strategy, workflow specs, campaign copy, copy grading and GTM flow charts on Miro
- `knowledge-base/playbooks/`: the method docs those skills read

## How to use it

Open Claude Code in your Context OS folder and paste:

> Clone github.com/bolaji-ships/gtm-starter-kit into a temporary folder. Copy its .claude/skills folders into our .claude/skills and its knowledge-base/playbooks files into our knowledge-base/playbooks. Delete the temporary folder, then list what you added.

Start a new Claude Code session afterwards so the skills load.
